# Clase 05 — Evaluación con casos, problemas, proyectos e investigación

Subir la carpeta `clase_05/` a la raíz del repositorio. El artefacto requiere `index.html` y `recursos.json` en la misma carpeta. Completar enlaces de NotebookLM en `recursos.json` para que se visualicen públicamente; los cambios locales del alumno no actualizan GitHub. Las respuestas se guardan en localStorage y se exportan por actividad a HTML o en respaldo JSON. No son entregas oficiales. Fuente: UNAM (2020), capítulos 13 a 16, páginas 225 a 298.
